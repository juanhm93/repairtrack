# AGENTS.md

## Cursor Cloud specific instructions

RepairTrack is a Laravel 13 (PHP 8.3) + Vue 3 + Inertia SaaS for managing repair
tickets. Today the repository only contains the auth/account foundation (landing
page, register, login, dashboard, account settings via Laravel Fortify); the
ticket/notification/billing features are still specs under `docs/`. The frontend
uses Vite + Tailwind v4; the database is SQLite (`database/database.sqlite`).

The update script only refreshes dependencies (`composer install`, `npm install`).
Everything else below persists in the VM snapshot after the initial setup, but
these notes matter when source changes or when starting fresh.

### Running the app (development)

- One command: `composer dev` runs the PHP server, queue worker, `pail` log
  tailer, and the Vite dev server together (via `concurrently`).
- Or run separately: `php artisan serve --host=0.0.0.0 --port=8000` and, in
  another terminal, `npm run dev`. The app is served at `http://localhost:8000`.

### Lint / type / test

- Full CI gate: `composer ci:check` (eslint + prettier check + phpstan + vue-tsc
  + phpunit). Individual pieces are the `package.json` scripts (`lint:check`,
  `format:check`, `types:check`) and Composer scripts (`composer test`,
  `./vendor/bin/pint --test`, `./vendor/bin/phpstan analyse`).

### Non-obvious gotchas

- Wayfinder generates TypeScript route/action helpers into
  `resources/js/{actions,routes,wayfinder}`. These are required for
  `npm run lint:check` (eslint `import/order`) and `npm run types:check`
  (`vue-tsc`) to pass. They are auto-generated by the Vite plugin during
  `npm run dev` / `npm run build`; to regenerate them without a full build run
  `php artisan wayfinder:generate --with-form`. If they are missing, eslint and
  vue-tsc fail with confusing import/type errors.
- PHP feature tests render Inertia pages, which require the built Vite manifest
  at `public/build/manifest.json`. Run `npm run build` before `php artisan test`
  / `composer ci:check`, otherwise those tests fail with
  `ViteManifestNotFoundException`.
- `resources/js/pages/Welcome.vue` is not Prettier-clean in the committed code,
  so `npm run format:check` (and therefore `composer ci:check`) currently reports
  a formatting issue on that file. This is a pre-existing code issue, not an
  environment problem.
- Use npm (there is a `package-lock.json`); this is what CI uses. A
  `pnpm-workspace.yaml` exists but is not the primary workflow. `.npmrc` sets
  `ignore-scripts=true`, so native/optional build scripts are skipped on install.
- Email verification is disabled (`MustVerifyEmail` is commented out in
  `app/Models/User.php`), so a freshly registered user lands directly on
  `/dashboard`.
